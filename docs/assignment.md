# 課題条件と提出の準備

## 必須条件（授業資料30ページ）

- AR.jsで実写映像とCGを重畳するARアプリケーションを作成。
- マーカー等は自作することが望ましい。
- Webアプリケーションをgithub.io等で公開し、URLを文書に記載。
- アプリ概要と動作画面を文書にまとめ、PDFで提出。
- マーカー画像をPDFに掲載し、別途画像ファイルでも提出。
- 期限：2026年11月16日（月）23:59、Teamsで提出。

## 本作品の概要

家の図案と右上の四角で方向を判別できる自作マーカーを認識すると、机の上に小さな住宅街を表示する。
中央のミニハウス、周囲の道路・木々・店舗・集合住宅を、A-Frameの基本図形とThree.jsの屋根形状で表現した。
昼夜切り替えとサイズ変更に対応。マーカーの移動や傾きに街が追従する。

## 実機で確認する項目

- [ ] HTTPSの公開URLでカメラが起動する。
- [ ] 自作マーカーを認識し、実写映像上に街が表示される。
- [ ] マーカーを動かすと街が追従する。
- [ ] マーカーを外すと街が消え、再度映すと復帰する。
- [ ] 昼夜とサイズ変更のボタンが動作する。
- [ ] 端末名・OS・ブラウザ・確認日を記録する。

## PDFの構成予定

1. 作品名、目的、使用技術、公開URL
2. 操作方法と実装の説明
3. 実写とCGが重なる動作画面（昼・夜など）
4. 自作マーカー画像、確認環境、考察

3Dプレビューの画面は、実写ARの動作画面の代用にはしない。
実機のカメラ撮影と追跡が確認できるまでは、確認済みとして記載しない。
